A swipeable carousel for plocks, built on react-native-reanimated-carousel. Part of [plocks](https://plocks.dev/): it builds on `@plocks/ui` and reads the same theme.

Contains `Carousel`.

## Installation

```bash
npm install @plocks/ui @plocks/carousel
```

## Usage

Render inside the `PlocksProvider` from `@plocks/ui`:

```tsx
import { Carousel } from '@plocks/carousel';

<Carousel>{slides}</Carousel>
```

See [plocks.dev](https://plocks.dev/) for every component, prop and example.
