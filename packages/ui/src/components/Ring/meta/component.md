The Ring component displays progress or status using a radial indicator. It supports custom labels, color stops, neutral states, and fully customized center content.

## Accessibility

The ring is a `progressbar` exposing `aria-valuemin/max/now` and the displayed value as `aria-valuetext`. Its name is `accessibilityLabel`, else the text of `caption`, else of `label`.
