# 0.2.0

This release adds accessible list interactions, improves chart layouts and touch feedback on small screens, and expands the component documentation and examples.

## Components

- Add `ReorderableList` with drag handles, keyboard move controls, and native accessibility actions. Native dragging requires `GestureHandlerRootView`.
- Add `SwipeableRow` with swipe actions and an accessible action menu. Wrap the app in `GestureHandlerRootView` to enable native swipe gestures.
- Add `LinkBox` for linked content blocks with normal browser link behavior.
- Extend `FloatingActions` with stack and flower layouts, persistent labels, trigger icons, and button variants.
- Make `Table`'s `vertical` variant transpose data into labeled rows.
- Improve dialog sizing, popover positioning, menu behavior, and keyboard navigation.
- Improve theme-aware text and control contrast on first paint and when changing color schemes.

## Charts

- Improve narrow-screen spacing, labels, legends, heatmap cells, and radial chart geometry.
- Keep touch-selected values visible briefly after release, with consistent dismissal and tooltip placement.
- Improve hit testing and tooltip content for dense charts, links, and distributions.
- Add `showLabelsOnNarrow` to `PieChart` for applications that need outside labels on small screens.

## Documentation and tooling

- Expand the home gallery to cover the complete catalog in shared responsive columns.
- Add component variant examples, browser interaction tests, and light/dark screenshot coverage.
- Improve documentation navigation, links, headings, examples, and generated agent documentation.
- Add a dedicated docs typecheck and commit visual regression baselines for CI.
- Update all packages and starter dependencies to the 0.2 release line.

## Upgrading

Update every installed `@plocks/*` package to `^0.2.0` together. The `^0.1.0` range does not include this release. Use `npm create plocks@0.2.0` for a new project after publishing.

`FloatingActions` now defaults to the stack layout; use `mode="flower"` for the radial layout. `Table variant="vertical"` now applies the documented transposed layout when using its `data` prop. Heatmap color-scale examples use `domain: [min, max]`.

`ReorderableList` and `SwipeableRow` remain beta components. Review their documentation before depending on their APIs.
