# 1.2.0 — systemic refactor (draft notes)

> Draft for merging into [1.2.0](1.2.0.md). Nothing here is linked from the changelog index yet.

This part of the release rebuilds the library on one set of shared primitives instead of a copy per component. Five things changed underneath almost every component:

- **One token source.** Sizes, spacing, radii, shadows, z-indexes and breakpoints all come from the theme, through `core/theme/tokens.ts`. `createTheme({ spacing, radii })` now actually changes the components.
- **Accessibility that reaches the web.** react-native-web ignores `accessibilityState` and `accessibilityValue`, so on the web no checkbox, switch, tab, select or slider ever reported its state. Every component now emits `role` and `aria-*`, which both platforms understand.
- **One overlay system.** Menus, tooltips, popovers, selects, pickers, dialogs and sheets share a single floating-overlay primitive and one layer stack. Escape and the Android back button close only the topmost layer, focus moves into overlays and back out, and nested overlays stack correctly on native.
- **One component contract.** Every component forwards a ref and takes typed `style`, `testID`, spacing and visibility props. No public prop type uses `any`.
- **Platform and RTL handled once.** Web-only behavior goes through `core/platform`. Layout uses logical properties, so RTL mirrors without per-component swaps.

## Things you will notice

### Sizing and layout

| Change | Before | After |
| --- | --- | --- |
| Control height at `md` | Button 40, IconButton/Chip/Toggle/SegmentedControl 36 | 40 everywhere (Chip, Badge, KeyCap and Pagination items are one step smaller by design) |
| Button, Stepper, Carousel, ClearButton at `xs`/`sm` | own table | canonical 28 / 32 |
| `radius="3xl"` | 24 (tokens) or 20 (theme) | 20 |
| `radius="full"` on Button | not a full pill at xs–md | a pill |
| PinInput cells at `md` | 48 | 40 |
| Pagination items | control size | one size smaller (`md` renders at `sm` height) |
| Breadcrumbs text at `md` | 16px | 14px (theme font scale) |
| Skeleton `radius="xl"` | 20 | 12 (the radius scale) |
| TextArea height | ~40px per row | rows × line height |

### Breakpoints

There is one breakpoint table now, and it lives on the theme: **xs 480, sm 576, md 768, lg 992, xl 1200**.

| Where | Before |
| --- | --- |
| `theme.breakpoints` | 480 / 768 / 1024 / 1280 / 1536 |
| Grid, MonthPicker, YearPicker | sm 480, md 640, lg 960 |
| AppShell | its own table, with `xs` at 0 on the CSS side |

If you used `Grid` spans at `md`, those columns now switch at 768 instead of 640.

Viewport-dependent components read one store that is safe during server rendering. On the server, a layout renders as desktop instead of flashing to mobile.

### Theme and CSS

- **Native shadows vary again.** The shadow parser used to reject every token, so all of them rendered the same fallback shadow on iOS and Android. Each token now renders its own shadow, and dark mode uses its own values.
- **New theme fields.** A resolved theme now has `controlSizes`, `zIndices`, `fontFamilyMono` and seven background roles: `borderStrong`, `hover`, `pressed`, `selected`, `disabled`, `mark` and `scrim`. Partial overrides are filled in for you. A hand-written *complete* `PlatformBlocksTheme` object must now include them.
- **The `theme` prop.**
  - It accepts `{ light, dark }` pairs, so a custom theme keeps light/dark switching.
  - A partial override now merges onto the current color scheme's built-in theme. It used to merge onto the light theme.
  - Use `getColorSchemeScript()` in your document head to avoid a flash of the wrong scheme.
- **CSS variables are renamed.** `--platform-blocks-color-*` is now `--platform-blocks-palette-*`, and `--platform-blocks-border-color` is now `--platform-blocks-bg-border`. There are new `--platform-blocks-bg-scrim` and `--platform-blocks-focus-ring` variables.
- **No more global `outline: none`.** The library used to remove focus outlines across the whole page, including your own inputs. Keyboard focus now shows a `:focus-visible` ring from `theme.states.focusRing`, with zero specificity so your styles win.
- **One z-index scale.** Values come from `theme.zIndices`: dropdown 1000, header 1200, modal 1400, popover 1500, toast 1600, tooltip 1700. A Popover no longer opens underneath the AppShell header.
- **Spacing props are logical.** They use `marginStart`/`marginEnd` and `paddingStart`/`paddingEnd`, so `ml`/`pr` and friends mirror in RTL. A physical `marginLeft` in your own `style` may now lose to `marginStart` on native.
- **Visibility props work.** `hiddenFrom`, `visibleFrom`, `lightHidden` and `darkHidden` now work on every component. They were typed on 59 components but implemented on one.

### Behavior

- **Accessible names.**
  - Button no longer announces itself as "Button" when its children aren't a plain string.
  - Icons are decorative unless given a label.
  - Icon-only controls warn in development when they have no name.
- **Checkbox, Switch and Radio.**
  - Each is one control with one tab stop; pressing its label toggles it.
  - Their `style` now applies to the whole field, not just the box.
- **RadioGroup, Tabs, SegmentedControl, ToggleGroup, Menu, Calendar and Pagination.**
  - One tab stop, with arrow keys moving between items (mirrored in RTL).
  - Pressing the already-active tab no longer fires `onChange`.
- **Refs.**
  - Select, AutoComplete, the date/month/year/time picker inputs, ColorInput and PinInput now give a `FieldHandle` ref (`focus`, `blur`, `clear`) instead of a View.
  - NumberInput and Slider now forward the ref they used to drop.
  - Link's ref is a `Text`.
- **Select.**
  - Its value type is preserved, and `onChange` receives `T | null`.
  - `searchable` now works.
- **AutoComplete.**
  - `value` is strictly controlled.
  - Local data filters immediately; only `onSearch` is debounced.
- **Overlays.**
  - Popover and Dialog: focus moves into the overlay and returns to the trigger on close (Popover `returnFocus` now defaults to true).
  - A Dialog title now shows even with `closable={false}`.
  - Tooltip: it opens on keyboard focus, closes on Escape, and defaults to an inverted surface.
  - Missing provider: overlays render inline instead of throwing.
- **Announcements.**
  - Toasts announce themselves on iOS too.
  - `Alert` uses `role="alert"` only for error and warning, and `role="status"` otherwise.
- **Callbacks.**
  - `PinInput.onComplete` fires once, when the code becomes complete; it used to fire on every parent re-render, which could submit an OTP twice.
  - `CopyButton.onCopy` fires only when copying succeeded. Failures go to the new `onCopyError`.
  - DataTable:
    - `onRowClick` fires on click as well as the keyboard.
    - Selection works without a `selectedRows` prop.
    - `onColumnVisibilityChange` no longer fires on mount.
- **Motion.** The OS reduce-motion setting is respected everywhere; it used to be ignored by about 20 components. Carousel autoplay pauses under reduced motion and on hover or focus, and shows a pause control.
- **Visual defaults.**
  - Highlight: dark-mode marks are amber.
  - ShimmerText: defaults to muted text with a primary sweep.
  - Tooltip: uses an inverted surface.
- **Labels.**
  - CopyButton in CodeBlock reads "Copy code".
  - Clear buttons read "Clear".
  - Alert's close button reads "Close".
- **No provider required.** `useSound()`, `useDirection()` and `useI18n()` work without their providers, so `direction={false}` on `PlatformBlocksProvider` no longer crashes.

### Types

Public types no longer use `any`. The only exceptions are three deliberate escape hatches for data you define yourself: `theme.other`, form values, and DataTable cell values. That makes a few signatures stricter:

- **`Select`:** `onChange` receives `T | null`. The value type comes from `options`.
- **i18n:**
  - `TranslationDictionary` is recursive, so nested dictionaries type-check.
  - `t()` params and function entries take `Record<string, unknown>`: annotate a function entry's params if it does arithmetic on them.
  - The provider's `i18nResources` is `I18nResources`.
- **`usePopoverPositioning` / `useDropdownPositioning`:** their refs are generic (`<TAnchor = View, TPopover = View>`). Pass a type argument when you attach one to a `TextInput`.
- **`PlatformBlocksProvider`:** `spotlightConfig.actions` is `SpotlightItem[]`.
- **Sound:** `createSound` / `SoundAsset.source` take a `SoundSource` (a `require` number, a URL string, or `{ uri }`).
- **Themes:** `ComponentTokenOverride` values are `unknown`, and `theme.other` is exported as the augmentable `PlatformBlocksThemeOther`.
- **`BaseInputProps`:** it's deprecated, and its `style` is typed `StyleProp<ViewStyle>`.

## Props that did nothing

**Now implemented:**
- Select `searchable`
- Slider `showMarks`, `inverted` and `tooltip`, plus `onChangeEnd` and `largeStep`
- RangeSlider `defaultValue`, `minRange` and `allowCross`
- ToggleGroup `defaultValue`
- PinInput `enforceOrderInitialOnly`
- Input `validation` and `debounceMs`
- Form `validation` and `validateWhen`, and `Form.Label htmlFor`
- FileInput `onProgress` and `uploadSettings`
- DataTable `headerBackgroundColor`, `hoverColor`, `borderColor` and `enhanced*`
- Table `highlightOnHover`, and `TableTr onPress`
- AudioPlayer `setSelection` / `clearSelection`, plus skip controls, the overlay controls position and keyboard shortcuts
- Carousel `scrollEnabled` and `arrowPosition="outside"`
- Gauge `color`, `backgroundColor`, `animationEasing` and the needle options
- TableOfContents `depthOffset` / `minDepthToOffset`
- CopyButton `iconOnly={false}` and `toastMessage`
- Breadcrumbs `href` (a real link on the web)

**Removed:**
- **Text-entry props that only existed through inheritance:** FileInput, Slider and PinInput lose `onChangeText`, `clearable`, `debounceMs`, `onEnter` and `startSection`; TextArea loses `onEnter` and `debounceMs`.
- **Popover:** `withinPortal`, `withOverlay`, `overlayProps`, `clickOutsideEvents`, `hideDetached`.
- **HoverCard:** `withinPortal`, `keepMounted`. **ContextMenu:** `portalId`.
- **DatePickerInput:** `valueFormat`. **ColorInput:** `format`, `withAlpha`. **Markdown:** `allowHtml`.
- **Waveform:** the zoom props and `enableAnimations`.
- **AudioPlayer:** about 20 unimplemented props, including `playlist`, `effects`, `exportOptions` and `spectrumOptions`. Their types remain exported, marked deprecated.

## New APIs

- **Tokens:**
  - Resolvers: `getControlSize`, `resolveSpacing`, `resolveRadius`, `resolveFontSize`, `resolveShadow`, `resolveScrim`, `getBreakpoints`, `onColor`, `getZIndex`.
  - Theming: `getColorSchemeScript` and `useSpacingStyles`.
- **Accessibility:** `a11yProps`, `useFieldA11y`, `useRovingFocus`, `useListNavigation`, `useAdjustable`, `announce`, and a single `useReducedMotion` + `ReducedMotionProvider` (mounted by `PlatformBlocksProvider`).
- **Overlays:** `useFloating`, `useLayer`, `OverlayHost`, `LayerScope`.
- **Platform:** `isWeb`, `isNative`, `isIOS`, `isAndroid`, `hasDOM`, `webStyle`, `webProps`.
- **Viewport:** `useViewport`, `useBreakpoint`.
- **Contract types:** `BaseProps`, `VisibilityProps`, `FieldHandle`, `RadiusValue`, `ColorProp`, `useVisibility`.
- **Hooks:** `useLatestCallback`, `useThemedStyles`, `useSoundOptional`, `useOptionalToast`.
- **Clipboard:** `useClipboard().copy()` now resolves to whether it succeeded.
- **Exports:**
  - About 250 sub-component, handle and supporting types are now exported from the root.
  - HoverCard, FormLayout, SoundButton, QRCodeSVG, WaveformSkeleton and the Table parts are also exported from the root.

## Requirements and packaging

- **Peer dependencies.**
  - `react-native >= 0.79`: the icon deep imports need Metro package exports.
  - `@tabler/icons-react-native >= 3.35`, `react-native-reanimated >= 3.5`, `react >= 18 < 20`.
  - Optional peers are now declared: `expo-clipboard`, `expo-navigation-bar`, `react-native-gesture-handler`, `react-native-webview`.
- **Build output.**
  - The CommonJS build loads with `require()`, and types resolve under `moduleResolution: nodenext`.
  - The package is 2.3 MB packed and 11.6 MB unpacked, down from 5.5 / 27.8.
- **CodeBlock.** It loads `react-syntax-highlighter` again in browser bundles; it had always fallen back to its built-in tokenizer.
- **Logging.** The library no longer logs to the console in production apps.
