# 0.1.0

The first release of plocks: a component library for React Native and the web, built on one theme and one set of layout, color and overlay primitives.

The library was previously published as `@platform-blocks/ui` and
`@platform-blocks/charts`. The replacements use new names and start their own
version line; migrate imports to `@plocks/ui` and `@plocks/charts`.

## Packages

| Package | What it is |
| --- | --- |
| `@plocks/ui` | Components, hooks and the theme system |
| `@plocks/dates` | Calendars and date, month, year and time pickers |
| `@plocks/charts` | SVG charts that size themselves to their container and read the same theme |
| `@plocks/code` | `CodeBlock` with syntax highlighting, and `Markdown` |
| `@plocks/media` | `AudioPlayer`, `Video`, and sound feedback |
| `@plocks/carousel` | A swipeable `Carousel` |
| `@plocks/spotlight` | A ⌘K command palette |
| `@plocks/brands` | Brand icons and buttons |
| `@plocks/qrcode` | Themeable QR codes |
| `@plocks/emoji-picker` | Searchable emoji picker |
| `@plocks/ui-snack` | Bundle for documentation examples in Expo Snack |
| `create-plocks` | App generator for the plocks templates |

Install the ones you use alongside `@plocks/ui`. Dates, code, media, carousel and spotlight are built on it; charts is standalone and reads the theme through `ChartThemeProvider`.

## Platform

Developed and tested on Expo SDK 57 / React Native 0.86 with Reanimated 4 and Worklets. React 18 or 19. The optional peers (`expo-haptics`, `expo-clipboard`, `expo-linear-gradient`, `@shopify/flash-list`, …) add behavior when installed and fall back gracefully when they are not.

## Highlights

- **One provider.** `PlocksProvider` at the root supplies the theme and mounts overlays, i18n, safe area, haptics, direction and reduced motion. Nest another `PlocksProvider` to scope a theme to a subtree. Every package reads it.
- **One color prop.** `color` (`c` on text) takes a palette token, `primary.6` shade syntax, a text role or any CSS color on every component. `resolveColorProp` resolves it the same way for your own components.
- **Short style props everywhere.** `w`, `h`, `miw`, `maw`, `mih`, `mah`, `bg` and `opacity` on every component; `c`, `fw`, `ff`, `lts`, `ta`, `lh`, `tt` on text.
- **Tokens from the theme.** Sizes, spacing, radii, shadows, z-indexes and breakpoints come from `createTheme`, so a custom theme changes every component.
- **An elevation ladder.** `Surface` and `theme.surfaces` give menus, popovers, dialogs and cards one background, border and shadow per level, in light and dark.
- **One overlay system.** Menus, tooltips, popovers, selects, pickers, dialogs and sheets share a layer stack: Escape and Android back close the topmost layer, and focus moves in and back out.
- **Accessible on both platforms.** Components emit `role` and `aria-*`, which React Native and react-native-web both understand.
- **Charts that fit their container** and measure their own margins from the labels they draw.
