# Example apps

Standalone Expo apps built with plocks (`@plocks/ui`). Each app has its own run instructions and an interactive screen.

- [DICOM viewer](https://github.com/platform-blocks/examples/blob/main/apps/dicom-viewer/README.md) — A local viewer for basic uncompressed grayscale DICOM files, with a synthetic study included.
- [Flutterflight](https://github.com/platform-blocks/examples/blob/main/apps/flutterflight/README.md) — A tap-to-flap arcade game with moving pipes, collisions, scoring, and restart.
- [Springstep](https://github.com/platform-blocks/examples/blob/main/apps/springstep/README.md) — A bouncing platform game with left/right steering, procedural platforms, scoring, and restart.
- [Signal News](https://github.com/platform-blocks/examples/blob/main/apps/signal-news/README.md) — An audio-news-inspired reading screen with search, saved stories, and a sample playback timer. Headlines and summaries are original sample content; no live feed or audio.
- [The Daily Edition](https://github.com/platform-blocks/examples/blob/main/apps/daily-edition/README.md) — An editorial news reader with sections, article detail, and a saved list. Stories are original sample content; no live feed.
- [Lettergrid](https://github.com/platform-blocks/examples/blob/main/apps/lettergrid/README.md) — A five-letter word game with six guesses and position-aware color clues.
- [Daymark](https://github.com/platform-blocks/examples/blob/main/apps/daymark/README.md) — A wellness dashboard with sample steps, activity, sleep, daily history, and quick logging. No wearable connection.
- [Calculator](https://github.com/platform-blocks/examples/blob/main/apps/calculator/README.md) — A four-function calculator with decimals, percent, sign change, and chained operations.
- [Idea Grid](https://github.com/platform-blocks/examples/blob/main/apps/idea-grid/README.md) — A searchable idea grid with detail views and saved pins. Art and ideas are local placeholders.
- [E-Reader](https://github.com/platform-blocks/examples/blob/main/apps/e-reader/README.md) — A modern story reader with spoken narration, word highlighting, and saved reading progress.
- [Wordtrail](https://github.com/platform-blocks/examples/blob/main/apps/wordtrail/README.md) — A four-question beginner Spanish lesson with answer feedback, progress, and score.
- [Baseball live visualizer](https://github.com/platform-blocks/examples/blob/main/apps/baseball-live/README.md) — A three-view game day app with scores, a pitch-by-pitch Gamecast, box score, play log, and standings. No live league feed.
- [Flight tracker](https://github.com/platform-blocks/examples/blob/main/apps/flight-tracker/README.md) — A searchable fictional flight list with route details, gate, times, and static route progress. No live tracking.
